# Yiran Liu · Research website

This Jekyll site is hosted on [GitHub Pages](https://lyrrrrrr.github.io/).

- Edit `_pages/about.md` for the research homepage.
- Edit `_pages/cv.md` for the web CV.
- Edit `_config.yml` for the public name and site metadata.
- The shared layout and stylesheet are `_layouts/research-home.html` and `assets/css/research-home.css`.

For local preview with Ruby and Bundler installed, run `bundle install` and then `bundle exec jekyll serve` from the repository root. GitHub Pages builds the publishing branch.
